# ADR-058 — C-13 statique, sans shadow runs ; external_locks de C-12

- **Date** : 2026-10-18
- **Statut** : acceptée
- **Composants** : C-13 (Determinism Analyzer) ; C-12, C-08 ; C-21 (shadow runs, absent)
- **Exigences** : PARTIE 5.13, R-217, R-400, R-401, T-220 à T-223 ; DM-08, DM-10 ;
  P-02 ; ADR-054, ADR-055, ADR-057
- **Demande** : Killian, 2026-10-18, « go la suite » (après C-12)

## Contexte

C-13 dit si une unité rend le même résultat observable pour les mêmes entrées, et si son
ordre est observable. La fiche combine une recherche statique de sources de
non-déterminisme et une vérification dynamique : 32 exécutions en shadow comparées
(T-223), dont le moteur (C-21) n'existe pas.

## Décision

1. **Sources recherchées statiquement**, sur les méthodes analysées du graphe d'appel
   (les appels sont lus tels qu'écrits, résolus ou non) et sur les effets composés de
   C-11 :
   - `SharedRandom` : appel vers `java/util/Random` ou une classe qui en descend,
     `RandomSource`, `RandomGenerator`, `ThreadLocalRandom`, `Math.random` ; accès au
     domaine `Random` ;
   - `SystemTime` : `System.currentTimeMillis`, `System.nanoTime`, `now` d'une classe de
     `java/time/`, `java/time/Clock` ; domaine `Time` ;
   - `IdentityHash` : `System.identityHashCode` ; `hashCode()` ou `toString()` de
     `java/lang/Object`, écrits tels quels ou atteints par le graphe (non surchargés) ;
   - `HashMapIteration` : `keySet`, `values`, `entrySet`, `iterator`, `forEach`,
     `spliterator`, `stream` d'une table de hachage du JDK (`HashMap`, `HashSet`,
     `IdentityHashMap`, `WeakHashMap`, `ConcurrentHashMap`, `Hashtable`) — l'influence de l'ordre sur
     la sortie n'est pas suivie : toute itération compte ;
   - `ExternalIo` : appel vers `java/io/`, `java/nio/file/`, `java/nio/channels/`,
     `java/net/` ; domaines `FileSystem`, `Network` ;
   - `NativeCall` : une méthode `ACC_NATIVE` dans le graphe ;
   - `Reflection` : le graphe a rencontré un appel réflexif (C-07) ;
   - `ThreadScheduling` : prise ou attente de verrou (mêmes appels que C-12) ;
   - `Unknown` : une partie du graphe reste inconnue (site non résolu, non exploré,
     cible sans code ou non analysable, troncature).
2. **`deterministic`** : `NO` dès qu'une source autre que `Unknown` est trouvée ;
   `UNKNOWN` si seule une partie inconnue empêche de conclure ; `YES` sinon. Une source
   trouvée ne prouve pas que la sortie en dépend : `NO` est prudent, et `UNKNOWN` comme
   `NO` interdisent TL3 et au-delà (R-401).
3. **Pas de shadow runs** : `verified_runs` et `mismatches` valent 0. La promotion qui
   exige 32 exécutions identiques (T-223) appartient au moteur de risque et à C-21 ; un
   `YES` statique ne la remplace pas. `rfx.det.shadow_mismatches` n'est pas publiée.
4. **`float_sensitive`** : vrai dès qu'une instruction d'arithmétique flottante
   (`fadd` … `drem`) apparaît dans le code analysé, ou que le graphe est incomplet
   (R-217 : toute réduction flottante parallélisée devra garder un ordre fixe, R-400).
5. **`order_sensitive`** : `NO` si l'unité est en lecture seule connue (écritures
   connues et vides, aucun effet de bord), `YES` si elle écrit ou a un effet de bord
   connus, `UNKNOWN` sinon. Quand les écritures sont inconnues, C-11 pose `mutates_world`
   par prudence : ce drapeau dérivé n'est pas un effet connu, et seul un ensemble d'effets
   sans part inconnue rend `YES`.
6. **C-12 reçoit C-13** : `main_thread_required = NO` devient atteignable pour une unité
   pure (ADR-057, décision 4).
7. **`external_locks` (DM-08), produit de C-12** : `Some([])` si le graphe est complet et
   que l'unité ne prend ni verrou ni `synchronized` ; `None` sinon — l'identité des
   verrous n'est pas connue, une liste serait inventée.

## Conséquences

- Tous les faits que C-08 attend existent désormais, sauf `order_deps` (C-06) : tant que
  C-06 manque, aucune unité n'a de dépendances complètes et tout descripteur reste
  `UNKNOWN` (ADR-054, ADR-056).
- T-220 et T-221 sont couverts ; T-222 (réduction flottante parallèle) et T-223 (shadow
  runs) attendent le moteur parallèle et C-21.
- Métriques `rfx.det.deterministic_ratio` et `rfx.det.nondet_sources{source=…}`, lues
  dans le statut (`det_deterministic`, et `det_sources`, un compte par source indexé par
  le discriminant de `NonDetSource`).
- Une unité pure, comme `Threads.readFrozen` dans les classes de test, atteint
  désormais `main_thread_required = NO`. Elle reste `UNKNOWN` pour C-08 tant que C-06
  manque.
