# ADR-010 — Licence du projet : Apache 2.0, avec NOTICE pour l'attribution

- **Date** : 2026-10-03
- **Statut** : accepté
- **Décideur** : Killian (JLSkyzer / Erinium Group). Hors du périmètre de décision de
  l'agent d'implémentation (contrat agent, section 5) : l'agent l'exécute et la consigne.
- **Exigences** : R-892 (licence choisie et déclarée avant toute publication publique),
  T-009 (LICENSE et NOTICE présents et cohérents), PARTIE 27.3

## Contexte

Jusqu'ici, `LICENSE` déclarait « tous droits réservés », en attendant cet ADR. Le dépôt
devient public, pour deux raisons données par le décideur :

- **l'intégration continue** de GitHub Actions est gratuite et sans plafond de minutes
  sur les exécuteurs standard pour un dépôt public ;
- **être crédité** si le projet est copié.

R-892 impose que la licence soit choisie avant la première publication publique.

## Décision

Licence **Apache 2.0**, et fichier **`NOTICE`** à la racine.

Ce qui sert la seconde raison n'est pas la licence seule, mais sa section 4 d) : toute
redistribution de l'œuvre ou d'une œuvre dérivée **doit conserver le fichier NOTICE**,
ou reproduire ses mentions d'attribution. C'est là que figure « Copyright 2026 JLSkyzer /
Erinium Group ». La section 4 c) impose en outre de conserver les mentions de droit
d'auteur des sources.

Le titulaire des droits reprend celui de l'ancien fichier `LICENSE`, « JLSkyzer /
Erinium Group », sans rien y ajouter.

## Ce qui a changé

| fichier | avant | après |
|---|---|---|
| `LICENSE` | tous droits réservés | texte officiel d'Apache 2.0, récupéré par l'API de GitHub (`licenses/apache-2.0`) pour être exact et reconnu |
| `NOTICE` | absent | attribution, mention Mojang, liste des composants tiers embarqués |
| `Cargo.toml` | `LicenseRef-AllRightsReserved` | `Apache-2.0` |
| `gradle.properties` | `mod_license=All Rights Reserved` | `mod_license=Apache-2.0`, que `mods.toml` affiche dans le jeu |
| `FoundationsTest` | attend l'ancienne licence | attend `Apache-2.0` |
| `README.md`, `SECURITY.md` | | licence, et SBOM complété |

`NOTICE` est rédigé en anglais, par exception à la règle du français : c'est un fichier
juridique lu par quiconque reprend le code, comme le texte de la licence lui-même.

## Compatibilité des composants tiers

La bibliothèque native embarque une vingtaine de composants (`cargo tree -p rfx-ffi -e
normal`), tous sous licence permissive compatible avec Apache 2.0 : MIT, Apache-2.0,
BSL-1.0, BSD-2-Clause, Unlicense. Le côté Java n'ajoute aucune dépendance d'exécution.
Aucun contenu de Minecraft, de Forge ni d'aucun mod n'est dans le dépôt : vérifié sur
tout l'historique, fichiers supprimés compris, avant la publication.

Le SBOM de `SECURITY.md` ne citait que trois dépendances, et omettait `xxhash-rust`
(BSL-1.0). Il est complété, et renvoie à `NOTICE` pour la liste exhaustive.

## Conséquences

- **Avant la première release publique** : joindre au JAR les textes complets des
  licences des composants embarqués. MIT exige que sa mention accompagne toute copie,
  binaire compris ; le dépôt, qui ne distribue aucun binaire, n'est pas concerné, la
  release le sera.
- La liste de `NOTICE` doit suivre les dépendances : toute dépendance ajoutée au
  binaire natif y entre, avec sa licence.
- Une licence permissive autorise la réutilisation, commerciale comprise. Elle n'empêche
  pas la copie : elle oblige à créditer, et c'est ce qui était demandé.
